Select the "Signalizer" folder plugin:
- Signalizer.vst for VST2.4
- Signalizer.vst3 for VST3

and copy into your ~/.vst or ~/.vst3 folder respectively - that should be it!

Signalizer also comes as a standalone in a folder with an executable you can run directly, and set up your audio I/O as you prefer. This folder can be placed anywhere you prefer.

SYSTEM REQUIREMENTS

- glibc 2.35 or newer, and libstdc++ from GCC 12 or newer.
  In practice: Ubuntu 22.04 or newer, Debian 12 or newer, Fedora 36 or newer, and derivatives
  such as Linux Mint 21+, Pop!_OS 22.04+, MX 23+ and the Debian-based audio distributions.
  Known not to work: RHEL / Rocky / AlmaLinux 9, which are older on both counts.
- A CPU with AVX support - any Intel Sandy Bridge or AMD Bulldozer or later (2011 onwards).
  Some low-power Celeron/Pentium chips (Gemini Lake and similar) lack AVX and will not run this.
- An X11 session. Under Wayland it runs through XWayland.

This release loads the following system libraries. All of them are part of a normal desktop
install, so you are unlikely to need to install anything:

- libstdc++.so.6, libgcc_s.so.1, libc.so.6, libm.so.6, libmvec.so.1
- libGL.so.1, libfontconfig.so.1, libfreetype.so.6
- libX11.so.6, libXext.so.6, libXcursor.so.1, libXinerama.so.1, libXrandr.so.2, libXss.so.1
- libgio-2.0.so.0
- libasound.so.2 (ALSA - the standalone only; the plugins do not need it)

If a plugin fails to load and you want to know why, this lists anything missing on your system:

$ ldd -r Signalizer.vst3/Contents/x86_64-linux/Signalizer.so | grep -E "not found|undefined"

No output means everything it needs is present.

Assuming you have a C++17 setup and placed the VST sdks in ../SDKs/*, you can build from scratch if you prefer by running:

$ git clone https://github.com/jthorborg/signalizer
$ python3 prepare.py
$ python3 build.py release

-------------------

If you're unsure about where your plugin folder is, it can be very custom and I'd advise to research the internet for your particular DAW if you didn't choose it yourself.
